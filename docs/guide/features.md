# 功能特性

当前覆盖书源阅读、服务端书架、本地书籍、跨设备进度和书架新章节自动检查。

## 阅读器

- 阅读页目录、书签、阅读设置、系统语音朗读（TTS）、自动阅读。
- 亮色/暗色主题和移动端阅读交互。
- 打开书籍前同步服务端最新进度。
- 恢复上次阅读会话时优先使用服务端进度。
- 章节正文缓存和批量缓存。

## 书源解析

- CSS Selector
- JSONPath
- XPath
- Regex
- JavaScript
- Legado 风格规则兼容
- 搜索、详情、目录、正文多阶段解析

## 服务端书架

- 添加、删除、分组、排序书籍。
- 最近阅读和阅读进度保存。
- SQLite 存储用户、书源、书架和阅读进度。
- 文件缓存保存章节内容和上传资源。

## 本地书籍

本地书籍会进入服务端书架，而不是只保存在某台设备的浏览器里。

- 支持上传 `.txt`、`.epub`、`.mobi`、`.pdf` 格式文件。
- 自动解析常见章节标题（TXT）或提取目录结构（EPUB）。
- 生成稳定的本地书籍 URL 和章节 URL。
- 支持服务端目录、正文读取和阅读进度保存。
- 删除书籍时清理导入文件。
- 本地书籍不显示远程章节缓存标签。

## 新章节自动检查

- 默认每 24 小时检查一次书架上所有网络书的目录（`CHAPTER_UPDATE_INTERVAL_HOURS` 可改）。
- 有更新的书在书名右边显示「新 N 章」，打开后消失。
- 书架上的「刷新书架」按钮会马上检查一次新章节。
- 同一书源串行、不同书源并发，避免把书源网站请求太频繁。

更多说明见 [新章节自动检查](./chapter-update)。

## RSS 和维护

- RSS 源管理、文章列表和文章阅读。
- WebDAV 备份/恢复书架、书源、阅读进度等数据。
- 服务端文件备份、下载、上传和删除。
- 书源导入导出。
