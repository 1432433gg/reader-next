# v1.1.7-beta.1 测试版

本测试版包含文字书源选择性导入、规则兼容改进和可选 Remote WebView。正式整合版本的前端、Rust 和受控运行时验收已有记录，欢迎在备份数据后测试自己的文字书源。

## 本次更新

- 本地文件、远程链接、手动订阅更新共用导入预览，支持筛选和勾选。重复书源默认跳过，覆盖需逐项确认，并检查预览后的数据变化。
- 改善新版嵌套规则、旧版扁平字段和字符串规则对象的导入，显示格式错误及登录、JavaScript / WebView 依赖提示。
- 手动检测只处理选中书源，默认并发3，可选1–6；日常多源搜索默认并发4。
- 动态文字源可通过 Remote WebView 执行浏览器脚本，已验证 GET、POST、中文正文、脚本结果及搜索到首章流程。
- 修复渲染请求兼容、任务取消、浏览器生命周期及敏感日志问题，并提供 Linux Docker 出站隔离配置。

## 安装测试镜像

镜像为 `ghcr.io/1432433gg/reader-next:1.1.7-beta.1`，包含 linux/amd64 和 linux/arm64。测试前请备份现有数据库、上传文件和配置。

从本测试标签检出配置文件后，在仓库根目录执行：

~~~bash
cp docker/env.docker.example docker/.env.docker
~~~

在 `docker/.env.docker` 中设置 `READER_IMAGE=ghcr.io/1432433gg/reader-next:1.1.7-beta.1`，并填写账户和端口配置。启动：

~~~bash
docker compose --env-file docker/.env.docker -f docker/compose.yml pull reader
docker compose --env-file docker/.env.docker -f docker/compose.yml up -d reader
~~~

## Remote WebView

当书源规则启用 `webView` 时，服务将请求交给浏览器渲染，再解析搜索、目录或正文。普通 HTTP 书源可以直接使用。缺少渲染配置时，动态书源会返回明确错误。

启用需 Linux Docker Engine 和支持 `!reset` 的 Compose，已有验证环境使用 Compose 5.7.0。在 `docker/.env.docker` 中填写：

~~~dotenv
REMOTE_WEBVIEW_URL=http://remote-webview:8050
EGRESS_DENY_CIDRS=你的宿主机公网IPv4/32 其他敏感IPv4网段
EGRESS_ALLOW_TCP=
~~~

将示例中的文字替换为真实地址。deny list 应覆盖全部宿主机公网/NAT地址及额外敏感网段。启动：

~~~bash
docker compose --env-file docker/.env.docker -f docker/compose.yml -f docker/compose.egress.yml --profile webview config
docker compose --env-file docker/.env.docker -f docker/compose.yml -f docker/compose.egress.yml --profile webview up -d --build
~~~

渲染器镜像需要本地构建，基础镜像及浏览器约1.48 GB。浏览器执行时的内存需求高于空闲状态，生产容量请按实际书源测量。默认渲染并发1，请求总时限15秒，8050仅通过容器网络访问。当前隔离预设使用公网IPv4，并拒绝新的IPv6出站连接。

兼容旧变量 `READER_APP_REMOTEWEBVIEWAPI`，新变量 `REMOTE_WEBVIEW_URL` 非空时优先。完整说明见 [Docker部署](https://github.com/1432433gg/reader-next/blob/v1.1.7-beta.1/docs/deploy/docker.md) 和 [渲染器出站隔离](https://github.com/1432433gg/reader-next/blob/v1.1.7-beta.1/docker/egress/README.md)。

## 使用范围与反馈

当前以文字书源和无需交互登录的动态源为验证范围。JavaScript专用接口、复杂登录、跨请求Cookie及特殊站点仍需逐源验证。发现问题时请提供版本、脱敏书源规则、复现步骤及错误信息，移除Cookie、令牌和个人凭据。
