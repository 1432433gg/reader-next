# 缓存归属与书架批量操作栏：本地修复和验收记录

本次修改基于 v1.1.4，开发阶段只推送代码、未发布镜像；随后与自定义封面功能一起纳入 v1.1.5。

## 问题与修复

### 缓存归属

正文请求原来只携带 chapterUrl 和 bookSourceUrl。服务端根据书架和网址前缀猜测书籍归属；未上架或章节网址结构不同的书，会以章节 URL 作为书籍缓存键保存。书架按真正的 bookUrl 统计时可能遗漏。这是已确认的代码缺陷，不代表已经核实用户截图中每本书的具体原因。

- 阅读、预加载、强制刷新和手动离线下载均携带明确的 bookUrl。
- 服务端优先使用 bookUrl，兼容没有该字段的旧客户端。
- 读取和统计时，恢复旧版以章节地址为键保存的缓存，只查找确切章节，不猜测其他书的目录。
- 清除和刷新同时处理旧键，避免旧内容再次出现；单章刷新保留其他章节。
- 统计对章节地址去重，保留用户命名空间隔离。

两端数量仍可合理不同，例如换设备或只清除了其中一端。不用浏览器缓存数量伪造服务端数量。已错误归入另一书籍目录的历史缓存不做全盘猜测迁移。

### 批量操作栏

操作栏原来写死 104px 的底部基准，和导航栏的响应式尺寸、安全区偏移不一致。

- 导航栏和操作栏共用偏移、高度及 10px 间距变量。
- 观察实际高度，窗口变化时重新测量；不依赖 iOS/Android UA 判断。
- 列表随操作栏高度留白，退出选择后撤销多余留白。
- 手机按钮至少 44px 高，窄屏允许换行；修正不存在的圆角变量。

## 尚未完成的验收

DOM 模拟测试不等于真实浏览器渲染或真机测试。当前本地浏览器启动失败；另一个测试浏览器的安全策略拒绝打开本地文件，未尝试绕过此限制。因此以下检查仍待执行：

| 环境 | 场景 | 验收要求 |
| --- | --- | --- |
| iOS Safari / PWA | 竖横屏、工具栏收放、底部安全区 | 两条浮栏间距 10px，按钮可点，末本书能完整滚入视区 |
| Android Chrome / PWA | 手势导航、三键导航、竖横屏 | 无重叠或横向溢出，分组、删除可用 |
| 桌面 Chrome / Edge / Firefox / Safari | 缩放、文字放大、编辑模式进出 | 重新测量并留白，退出编辑无多余空白 |
| 320 / 360 / 390 / 640 / 641 / 768 / 1440px | 断点两侧、安全区 0 / 34px | 实际间距一致、按钮不被挤出、末项不被挡住 |
| 各端实际书源 | 搜索后直接读、先上架再读、离线、刷新、清缓存 | 请求带 bookUrl，显示真实缓存数，不出现旧缓存复活 |
