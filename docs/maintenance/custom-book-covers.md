# 自定义书籍封面

## 使用

在书架点击书籍封面进入详情，选择「更换封面」。选图后显示预览，点击「保存封面」才上传；「取消」不修改原封面。「恢复默认」显示原书封面，没有原图时显示书名占位图。

适用于已加入书架的本地书和书源书。支持 JPG、PNG、WebP，原文件最大 5MB。手机使用系统图片/文件选择器；HEIC 暂不直接支持，需转换为支持的格式。按钮最小高度 44px，窄屏宽度自适应，浅色/深色使用现有主题变量。

## 保存与读取

- 复用 `Book.customCoverUrl`，自定义封面优先于 `coverUrl`。
- `POST /reader3/uploadBookCover?bookUrl=...`：multipart 的 `file` 字段；只修改当前用户书架里的书。
- `POST /reader3/resetBookCover`：JSON `{ "bookUrl": "..." }`；只清除自定义封面，不修改进度、目录、章节缓存。
- `GET /reader3/bookCover/:id`：UUID 图片地址，返回 JPEG。与原封面一样可通过不带登录头的 `<img>` 读取；知道完整随机地址的人可以访问图片，上传和重置仍校验书籍归属。
- 文件存放于 `${STORAGE_DIR}/book-covers/<uuid>.jpg`，包含在现有 Docker `/app/storage` 持久化卷中。
- 前端按比例压缩并预览。服务端再次解码、限制尺寸/内存，缩到 600×900 以内，透明区域铺白后重新编码 JPEG，去掉原始元数据，不使用上传文件名。
- 每次上传使用新 UUID 和不可变缓存头，避免浏览器继续显示旧图。失败时保留原封面；书架图片加载失败状态在地址变化后重置。
- 普通 `saveBook` / `saveBooks` 对已有书籍保留服务器当前的自定义封面，避免旧设备的排序或进度保存覆盖它。封面更改须使用专用接口。换源复制书籍时携带自定义封面。
- 书架写操作串行化，JSON 用临时文件原子替换，避免同时保存进度/封面丢失修改或读到部分文件。
- 旧封面文件暂时保留，兼容其他设备的旧书架记录和历史备份；本版不自动清理孤立图片。

## WebDAV

新备份格式版本为 2，包含自定义封面 JPEG 的 Base64 数据，同一图片只备份一次。恢复到另一台服务器时重新上传并关联新地址。版本 1 的备份仍可读取，但无法恢复本来未包含的图片文件。远程书源图片不内嵌进备份。
